# Инженерная практика агентных систем — том 2

Программное сопровождение монографии «Инженерная практика агентных систем», том второй серии «Прикладной искусственный интеллект».

Авторы: П. А. Пылов, Р. В. Майтак, А. В. Протодьяконов.
Версия комплекта: 1.0.0 от 14/10/2026 года.
Репозиторий: https://github.com/MaytakRoman/agent-systems-engineering-vol2

## Запуск

Требуется Python 3.10 или новее. Внешние библиотеки, API, сеть и GPU не нужны.
Проверенное окружение: Linux, Python 3.12.14. Проверка на Windows/macOS не выполнялась.

Распакуйте комплект и запустите из его корня:

```sh
python run_all.py
```

На macOS/Linux команда интерпретатора может называться `python3`.
Сценарий запускает все 42 Python-листинга отдельными процессами, сохраняет полный вывод
в `execution_logs/` и коды завершения в `execution_report.json`. Четыре файла `*_schema.json`
проверяются на синтаксис JSON. Это не замена валидации запросов по диалекту JSON Schema 2020-12.

Альтернативный последовательный запуск из приложения А:

```sh
sh run_examples.sh
```

Переменная окружения `PYTHON` позволяет выбрать интерпретатор для shell-сценария;
по умолчанию используется `python3`. На Windows используйте `python run_all.py`.
Отдельный пример запускается по имени, например `python framework_checks.py`.
Локальные импорты требуют размещения исходников в одной папке; `batch_manifest.py`
должен запускаться из корня, где находятся четыре файла кейса главы 6.

## Состав

- 42 файла Python — все исполняемые листинги глав 1–10 и полный `framework.py` приложения А.
- `run_examples.sh` — сценарий приложения А.2.
- `read_schema.json`, `draft_schema.json`, `publish_schema.json`, `operation_schema.json` — схемы приложения Б.
- `run_all.py` — дополнительный сценарий общего запуска и записи журналов.
- `LISTINGS.md` — соответствие всех 47 листингов файлам и разделам книги.
- `execution_logs/` — 42 журнала Python-программ и журнал проверки shell-сценария.
- `execution_report.json` — фактические результаты запуска программ, чтения JSON и проверки shell-сценария.
- `case_manifest.json` — хеши четырёх файлов учебного кейса главы 6, созданные `batch_manifest.py`.
- `SHA256.json` — хеши файлов комплекта; сам манифест в свой состав не входит.

Код извлечён из рукописи без изменения алгоритмов и проверок.
При извлечении сохранены отступы, восстановлены переводы строк, представленные в DOCX
разрывами строк внутри абзацев. Печатный текст книги в программный комплект не включён.

## Проверка и результаты

Все 42 Python-листинга выполнились с нулевыми кодами завершения.
Сценарий `run_examples.sh` также исполнен целиком и завершился успешно.
Четыре JSON-документа прочитаны стандартным JSON-парсером.
Встроенные утверждения проверяют положительные и отрицательные случаи из книги.
Конкретные результаты и ошибки, если они возникнут при повторе, сохраняются в журнале.
Прохождение этих проверок относится к включённым конечным сценариям, а не к произвольным агентам.

Стенд `enterprise_case.py` воспроизводит 1 принятый случай, 1 случай запроса сведений и 3 отклонённых.
В конечной среде `qlearning.py` целевая награда даёт 20 принятых эпизодов из 20
при 40 вызовах на каждом из трёх проверенных seed; бонус за чтение даёт 0 приёмок
и 20 усечённых эпизодов при 400 вызовах. Эти показатели относятся к табличной среде,
а не к обучению языковой модели.

## Границы примеров

Все внешние операции заменены локальными учебными моделями.
SQLite, автомат интерфейса, память, допуск и журнал демонстрируют ограниченные свойства,
описанные в соответствующих разделах книги. Примеры не выполняют публикации, рассылки,
запись в сторонние сервисы или реальные операции предприятия.

В частности, локальная атомарность не доказывает распределённую exactly-once семантику;
проверка цепочки хешей не аутентифицирует её автора; синтетический стенд не устанавливает
надёжность реального UI или MCP-транспорта. Экономические параметры условные.
Воспроизводимость проверена для сохранённых сценариев, без утверждения о промышленной готовности.

Повторный запуск обновляет журналы, `execution_report.json` и `case_manifest.json`.
Для сохранения предыдущего опыта используйте отдельную копию каталога.
После изменения отслеживаемых файлов контрольные суммы необходимо пересчитать.
